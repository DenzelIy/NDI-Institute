# Niger Delta Institute of Digital Technology — website

Static site. No build step, no dependencies. Six files.

```
index.html        Home
programmes.html   Fourteen certificates, five detailed for January 2027
admissions.html   Entry, routes, process, selection, fees framework, enquiry form
diploma.html      Diploma pathway and interest register
about.html        Governance, quality assurance, recognition position
contact.html      Contact routes and organisation details
styles.css        Shared stylesheet
```

## Deploying

Target domain: **nigerdeltainstitute.org**

Vercel, from this folder:

```
npx vercel --prod
```

Or drag the folder into any static host (Netlify, Cloudflare Pages, GitHub Pages). Point the domain at it and add a redirect from `www`.

## Before it goes live

1. **Closing date for the January 2027 intake.** Referenced on `admissions.html` as "published on this page". Insert the actual date.
2. **Fee schedule.** Band structure is on the page; the figures are a Board decision and are not stated. Add them under the Fees heading using the N prefix.
3. **Forms.** Both forms currently compose an email to `info@nigerdeltainnovate.org` because there is no endpoint. Replace with the Loop application endpoint or a form service, and add a privacy notice under the Nigeria Data Protection Act 2023 before collecting data at scale.
4. **Graphic Design specialist block.** Described in outline only. Drop in GRD 121–123 titles and descriptions from the approved specification.
5. **Safeguarding lead.** `contact.html` refers to "our named safeguarding lead". Name them, or route to a dedicated address.
6. **Logo.** The header uses a three-bar mark in the NDI accent colours as a placeholder. Swap in the NDI logo asset at 60px height, and add a favicon and an Open Graph image.
7. **Photography.** The site currently carries no images. RAIL, the STEM Fair and club sessions would carry the practical claims better than any stock photograph.

## Language rules applied

British spelling. No em dashes. "Board of Directors" and "Directors" only. The banned number does not appear anywhere; contact details are `info@nigerdeltainnovate.org`, +234 806 726 0598, and WhatsApp +234 818 195 8816.

Every page carries, in the footer and in a notice block, the approved form of words on recognition. No page states or implies that any programme is NBTE-accredited, government-approved or nationally recognised. Do not edit that wording without the Executive Director.
